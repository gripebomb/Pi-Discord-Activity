# Plan 02: Debounce and Graceful Shutdown

## Objective

Improve debounce logic to prevent Discord presence flickering during rapid tool calls, and ensure graceful shutdown clears presence reliably on all exit paths.

## Context

### Debounce Issues (RUNT-02)

The current debounce in `src/helper/index.ts` uses a simple time-based check:
```typescript
if (now - lastSentAt < defaultConfig.debounceMs) {
  return;
}
```

This doesn't account for state consolidation - rapid state changes like `thinking → tooling → thinking` still cause multiple Discord updates.

### Shutdown Issues (RUNT-04)

Current shutdown only handles SIGINT/SIGTERM. Uncaught exceptions and unhandled rejections don't clear presence before exit.

## Tasks

### Task 1: Implement state-consolidating debounce

<read_first>
- src/helper/index.ts
- src/shared/config.ts
</read_first>

<action>
Refactor the helper debounce to:
1. Only update Discord if the presence state actually changed
2. Use a sliding window that resets on each update
3. Consolidate rapid back-and-forth state changes

```typescript
// In src/helper/index.ts, modify the handlePresence function:

const discord = new DiscordPresenceClient();
let lastSentAt = 0;
let lastSentPayload: PresencePayload | null = null;
let pendingUpdate: NodeJS.Timeout | null = null;

async function handlePresence(payload: PresencePayload): Promise<void> {
  // If we have a pending update, clear it
  if (pendingUpdate) {
    clearTimeout(pendingUpdate);
    pendingUpdate = null;
  }
  
  // Check if this is a significant change from last sent state
  const isSignificantChange = !lastSentPayload || 
    lastSentPayload.state !== payload.state ||
    lastSentPayload.model !== payload.model ||
    lastSentPayload.provider !== payload.provider ||
    lastSentPayload.projectName !== payload.projectName;
  
  if (!isSignificantChange) {
    // Same state, no need to update
    return;
  }
  
  const now = Date.now();
  const timeSinceLastSend = now - lastSentAt;
  
  if (timeSinceLastSend < defaultConfig.debounceMs) {
    // Schedule update for after debounce period
    pendingUpdate = setTimeout(async () => {
      pendingUpdate = null;
      await sendPresence(payload);
    }, defaultConfig.debounceMs - timeSinceLastSend);
    return;
  }
  
  // Send immediately
  await sendPresence(payload);
}

async function sendPresence(payload: PresencePayload): Promise<void> {
  lastSentAt = Date.now();
  lastSentPayload = payload;
  await discord.setPresence(payload);
}
```

Also add a flush function for shutdown:
```typescript
function flushPendingUpdate(): void {
  if (pendingUpdate) {
    clearTimeout(pendingUpdate);
    pendingUpdate = null;
  }
}
```
</action>

<acceptance_criteria>
- Helper does not send duplicate presence for identical state
- Helper consolidates rapid back-and-forth state changes (e.g., thinking → tooling → thinking → tooling = single tooling)
- Helper waits full debounce period before sending after last change
- Helper has flushPendingUpdate() function for shutdown
</acceptance_criteria>

### Task 2: Add graceful shutdown handlers

<action>
Enhance shutdown handling to cover all exit paths:

```typescript
export async function startHelper(): Promise<void> {
  await discord.connect();
  createPresenceServer(handlePresence);

  // Add flush before any shutdown
  const shutdown = async (signal: string) => {
    console.log(`Received ${signal}, shutting down gracefully...`);
    
    // Flush any pending presence update
    flushPendingUpdate();
    
    // Clear Discord presence before exit
    await discord.clearPresence();
    
    // Give Discord RPC time to flush
    await new Promise(r => setTimeout(r, 100));
    
    console.log("Shutdown complete");
    process.exit(0);
  };

  process.on("SIGINT", () => void shutdown("SIGINT"));
  process.on("SIGTERM", () => void shutdown("SIGTERM"));
  
  // Handle uncaught exceptions
  process.on("uncaughtException", async (error) => {
    console.error("Uncaught exception:", error);
    flushPendingUpdate();
    await discord.clearPresence();
    await new Promise(r => setTimeout(r, 100));
    process.exit(1);
  });
  
  // Handle unhandled promise rejections
  process.on("unhandledRejection", async (reason, promise) => {
    console.error("Unhandled rejection at:", promise, "reason:", reason);
    flushPendingUpdate();
    await discord.clearPresence();
    await new Promise(r => setTimeout(r, 100));
    process.exit(1);
  });
}
```
</action>

<acceptance_criteria>
- Helper clears Discord presence on SIGINT
- Helper clears Discord presence on SIGTERM
- Helper clears Discord presence on uncaughtException
- Helper clears Discord presence on unhandledRejection
- Helper waits 100ms after clearPresence before process.exit
</acceptance_criteria>
