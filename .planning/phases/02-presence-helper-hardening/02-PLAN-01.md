# Plan 01: Discord RPC Reconnection Logic

## Objective

Add automatic reconnection to Discord RPC client so presence survives Discord desktop restarts and transient connection failures.

## Context

The current `DiscordPresenceClient` in `src/helper/discord.ts` connects once on startup and has no reconnection logic. When Discord desktop restarts or the RPC connection drops, the helper stops updating presence without recovering.

## Tasks

### Task 1: Add disconnected event handler

<read_first>
- src/helper/discord.ts
</read_first>

<action>
Add a `disconnected` event handler to the RPC client and a `ready` flag management:

```typescript
// In DiscordPresenceClient class, add:
private ready = false;
private reconnectAttempts = 0;
private readonly maxReconnectAttempts = 3;
private reconnectTimer: NodeJS.Timeout | null = null;

// Modify connect() method to set ready flag:
async connect(): Promise<void> {
  if (this.ready) return;

  this.client.on("ready", () => {
    this.ready = true;
    this.reconnectAttempts = 0;
    console.log("Discord RPC connected");
  });

  this.client.on("disconnected", () => {
    this.ready = false;
    console.log("Discord RPC disconnected");
    this.scheduleReconnect();
  });

  await this.client.login({ clientId: defaultConfig.rpcClientId });
}
```

Add the `scheduleReconnect()` and `attemptReconnect()` private methods:

```typescript
private scheduleReconnect(): void {
  if (this.reconnectTimer) {
    clearTimeout(this.reconnectTimer);
  }
  
  const delay = Math.min(1000 * Math.pow(2, this.reconnectAttempts), 5000);
  console.log(`Scheduling reconnect attempt ${this.reconnectAttempts + 1} in ${delay}ms`);
  
  this.reconnectTimer = setTimeout(() => {
    this.attemptReconnect();
  }, delay);
}

private async attemptReconnect(): Promise<void> {
  if (this.reconnectAttempts >= this.maxReconnectAttempts) {
    console.log("Max reconnection attempts reached, giving up");
    return;
  }
  
  if (this.ready) {
    console.log("Already reconnected, skipping");
    return;
  }
  
  try {
    console.log(`Attempting reconnect (${this.reconnectAttempts + 1}/${this.maxReconnectAttempts})...`);
    await this.client.login({ clientId: defaultConfig.rpcClientId });
    this.ready = true;
    this.reconnectAttempts = 0;
    console.log("Discord RPC reconnected successfully");
  } catch (error) {
    this.reconnectAttempts++;
    console.error(`Reconnect attempt failed:`, error);
    this.scheduleReconnect();
  }
}
```
</action>

<acceptance_criteria>
- DiscordPresenceClient has `disconnected` event listener
- DiscordPresenceClient has `scheduleReconnect()` method
- DiscordPresenceClient has `attemptReconnect()` method with exponential backoff (1s, 2s, 4s, max 5s)
- Max 3 reconnection attempts before giving up
- Logs reconnection attempts to console
</acceptance_criteria>

### Task 2: Queue presence updates during reconnection

</read_first>

<action>
Add a pending presence queue and apply it on reconnect:

```typescript
// In DiscordPresenceClient class, add:
private pendingPresence: PresencePayload | null = null;

// Modify setPresence() to queue updates during disconnection:
async setPresence(payload: PresencePayload): Promise<void> {
  // Always store the latest presence for when we reconnect
  this.pendingPresence = payload;
  
  if (!this.ready) {
    console.log("Discord RPC not ready, queuing presence update");
    // Don't throw - just queue it
    return;
  }

  const stateParts = [payload.model, humanizeState(payload.state)];
  if (!payload.privacyMode && payload.projectName && defaultConfig.includeProjectName) {
    stateParts.push(payload.projectName);
  }

  await this.client.setActivity({
    details: `Using ${defaultConfig.appName}`,
    state: stateParts.join(" • "),
    startTimestamp: payload.startedAt,
    largeImageKey: "pi",
    largeImageText: defaultConfig.appName,
    smallImageKey: normalizeKey(payload.provider),
    smallImageText: payload.provider
  });
}

// Modify ready handler to apply pending presence on reconnect:
this.client.on("ready", () => {
  this.ready = true;
  this.reconnectAttempts = 0;
  console.log("Discord RPC connected");
  
  // Apply any pending presence on reconnect
  if (this.pendingPresence) {
    console.log("Applying queued presence after reconnect");
    await this.setPresence(this.pendingPresence);
  }
});
```
</action>

<acceptance_criteria>
- DiscordPresenceClient has `pendingPresence` field
- setPresence() queues updates when not ready (doesn't throw)
- On reconnect, queued presence is applied automatically
- Multiple updates during disconnection result in only the last one being applied
</acceptance_criteria>
