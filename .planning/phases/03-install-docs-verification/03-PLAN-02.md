## OS Service Recipes for pi-discord-presence Helper

### Overview
The helper daemon can run as a background service using your OS's native service manager. This ensures the helper starts automatically and stays running for reliable Discord presence updates.

### Prerequisites
- Built project: `npm run build`

### macOS: launchd (User Service)

**Create Service File**:
```bash
# Create the service file
mkdir -p ~/Library/LaunchAgents
cat > ~/Library/LaunchAgents/pi.discord.presence.plist << 'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>pi.discord.presence</string>
    <key>ProgramArguments</key>
    <array>
        <string>/usr/local/bin/node</string>
        <string>/absolute/path/to/your/pi-discord-presence/dist/cli/run-helper.js</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
    <key>StandardOutPath</key>
    <string>/tmp/pi-discord-presence.log</string>
    <key>StandardErrorPath</key>
    <string>/tmp/pi-discord-presence-error.log</string>
    <key>WorkingDirectory</key>
    <string>/absolute/path/to/your/pi-discord-presence</string>
    <key>EnvironmentVariables</key>
    <dict>
        <key>DISCORD_RPC_CLIENT_ID</key>
        <string>your_discord_client_id</string>
        <key>PI_PRESENCE_PORT</key>
        <string>42666</string>
        <key>PI_PRESENCE_HOST</key>
        <string>127.0.0.1</string>
    </dict>
</dict>
</plist>
EOF
```

**Load Service**:
```bash
# Load the service
launchctl load ~/Library/LaunchAgents/pi.discord.presence.plist

# Start the service
launchctl start pi.discord.presence

# Check status
launchctl list | grep pi.discord.presence

# View logs
tail -f /tmp/pi-discord-presence.log
```

**Unload Service**:
```bash
# Stop and unload
launchctl stop pi.discord.presence
launchctl unload ~/Library/LaunchAgents/pi.discord.presence.plist
```

### Linux: systemd (User Service)

**Create Service File**:
```bash
# Create the service directory
mkdir -p ~/.config/systemd/user

# Create the service file
cat > ~/.config/systemd/user/pi-discord-presence.service << 'EOF'
[Unit]
Description=Pi Discord Presence Helper
After=network.target

[Service]
ExecStart=/usr/bin/node /absolute/path/to/your/pi-discord-presence/dist/cli/run-helper.js
WorkingDirectory=/absolute/path/to/your/pi-discord-presence
Restart=always
RestartSec=5
Environment=DISCORD_RPC_CLIENT_ID=your_discord_client_id
Environment=PI_PRESENCE_PORT=42666
Environment=PI_PRESENCE_HOST=127.0.0.1
StandardOutput=file:/tmp/pi-discord-presence.log
StandardError=file:/tmp/pi-discord-presence-error.log

[Install]
WantedBy=default.target
EOF
```

**Load Service**:
```bash
# Reload systemd
systemctl --user daemon-reload

# Enable service (start on login)
systemctl --user enable pi-discord-presence.service

# Start service now
systemctl --user start pi-discord-presence.service

# Check status
systemctl --user status pi-discord-presence.service

# View logs
journalctl --user -u pi-discord-presence.service -f
```

**Unload Service**:
```bash
# Stop and disable
systemctl --user stop pi-discord-presence.service
systemctl --user disable pi-discord-presence.service
```

### Windows: NSSM (Non-Sucking Service Manager)

**Install NSSM**:
```powershell
# Download NSSM from https://nssm.cc
# Or install with winget (if available)
winget install NSSM
```

**Create Service**:
```powershell
# Install service with NSSM
nssm install "Pi Discord Presence Helper" "C:\Program Files\nodejs\node.exe" "C:\absolute\path\to\your\pi-discord-presence\dist\cli\run-helper.js"

# Set working directory
nssm set "Pi Discord Presence Helper" AppDirectory "C:\absolute\path\to\your\pi-discord-presence"

# Set environment variables
nssm set "Pi Discord Presence Helper" AppEnvironmentExtra "DISCORD_RPC_CLIENT_ID=your_discord_client_id" "PI_PRESENCE_PORT=42666" "PI_PRESENCE_HOST=127.0.0.1"

# Set restart options
nssm set "Pi Discord Presence Helper" AppRestartDelay 5000
nssm set "Pi Discord Presence Helper" AppThrottle 1500

# Configure logging
nssm set "Pi Discord Presence Helper" AppStdout "C:\temp\pi-discord-presence.log"
nssm set "Pi Discord Presence Helper" AppStderr "C:\temp\pi-discord-presence-error.log"
```

**Manage Service**:
```powershell
# Start service
nssm start "Pi Discord Presence Helper"

# Check status
nssm status "Pi Discord Presence Helper"

# Stop service
nssm stop "Pi Discord Presence Helper"

# Remove service
nssm remove "Pi Discord Presence Helper" confirm
```

3. **Permissions**: User services don't require admin rights
4. **Logs**: Check log files for troubleshooting connection issues
5. **Testing**: Test the helper manually (`npm start`) before setting up as service
