**<action>**
Create `docs/discord-setup.md` with the following structure:

1. **Discord Developer Portal Setup**
   - Navigate to https://discord.com/developers/applications
   - Click "New Application"
   - Name it (e.g., "Pi Presence" or custom name)
   - Copy Application ID (Client ID)

2. **Enable Rich Presence**
   - Go to "Bot" section
   - Enable "Rich Presence" under Privileged Gateway Intents
   - Save changes

3. **Upload Image Assets**
   - Go to "Rich Presence" → "Art Assets"
   - Upload required images (match keys used in `src/helper/discord.ts`):
     - `pi` - Pi logo/branded image
     - `openai` - OpenAI provider image (optional)
     - `anthropic` - Anthropic provider image (optional) 
     - `google` - Google provider image (optional)

4. **Get Client ID**
   - From OAuth2 → General
   - Copy "Client ID"

5. **Environment Configuration**
   - Create `.env` file in project root:
     ```
     DISCORD_RPC_CLIENT_ID=your_client_id_here
     ```
   - Or set environment variable:
     ```bash
     export DISCORD_RPC_CLIENT_ID="your_client_id_here"
     ```

6. **Using Default App**
   - Note: Default app `1495329514417426522` works immediately
   - Custom app provides custom branding

Include screenshots for each step where appropriate.

## Installation: pi-discord-presence

### Prerequisites
- Node.js 20+
- npm 10+
- Discord desktop app running locally
- Pi coding agent installed locally

### Step 1: Discord Setup
1. Configure Discord application (see `docs/discord-setup.md`)
2. Get your Discord Client ID
3. Set environment variable:
   ```bash
   export DISCORD_RPC_CLIENT_ID="your_client_id_here"
   ```
   Or use default: `1495329514417426522`

### Step 2: Build the Project
```bash
git clone https://github.com/your-username/pi-discord-presence.git
cd pi-discord-presence
npm install
npm run build
```

### Step 3: Install Pi Extension
**Option A: Local Installation (Development)**
```bash
# Link extension to Pi's extension directory
mkdir -p ~/.pi/agent/extensions
ln -s $(pwd)/dist/extension/index.js ~/.pi/agent/extensions/pi-discord-presence.js
```

**Option B: Package Installation**
```bash
# Install from current directory (requires pi-package keyword)
pi install .
```

**Option C: Global Installation**
```bash
# Package for global use (advanced)
npm pack
# Install the .tgz file globally
```

### Step 4: Start Helper Service
**Development Mode:**
```bash
npm start
# or
npm run dev:helper
```

**Background Service:** (see `docs/service-recipes.md`)

### Step 5: Verify Installation
See `docs/verification.md` for complete verification steps.

### Troubleshooting
- Discord not updating? Check Discord app configuration and client ID
- Extension not loading? Verify file paths and permissions
- Helper not starting? Check Node.js version and dependencies
